# Контрольные примеры для next-stage

Эти примеры проверяют выбор ближайшего действия при изменении правил `next-stage`. Каждый случай привязан к историческому моменту. Для прогона передай проверяющему первые два поля и попроси назвать ближайшее действие и его основание. Затем сверь ответ с третьим полем. Для второй попытки измени только условие из четвёртого поля.

Четвёртое поле задаёт условный вариант. Более позднее фактическое событие включается во вход только того примера, к моменту которого оно уже произошло.
