# G‑09 · Проверка истечения сессии в NVDA

23 ноября 2026 года проверена локальная сборка исправления [Issue #230](https://github.com/vbondarev/intelligence.trade.system/issues/230) на базе `develop` `e7acc44f84d944d2d70dc0f91c74e461d2bb6f9f`. Среда — Windows 10.0.26300.0, Chrome 157.0.8103.79, NVDA 2026.3.1, русский язык, OneCore Microsoft Irina. Реальные вход Identity/BFF и realtime, синтетические данные карточки позиции. Срок сессии 3 минуты был задан временным override отдельного Compose-стенда.

## Воспроизведение

1. Открыть Speech Viewer, выбрать настройку автоматического Say All, начать новый контекст Chrome и выполнить штатный вход через Identity.
2. Открыть карточку позиции, дождаться предупреждения. В первой паре прогонов закрыть его кнопкой «Продолжить без продления», во второй оставить открытым до истечения сессии.
3. Дождаться реального `401` от `GET /bff/auth/session/timing`, записать речь, состояние диалога и фокус. После окончания речи нажать Enter и проверить, что запрос повторного входа содержит исходный маршрут.

## Результаты

| Предупреждение | Автоматический Say All | Speech Viewer | Диалог, фокус и Enter |
|---|---|---|---|
| Закрыто | Выключен | «Сессия завершена», краткое описание, «Войти снова». Название кнопки произнесено дважды. | PASS |
| Закрыто | Включён | «Сессия завершена», краткое описание, «Войти снова». Название кнопки произнесено дважды. | PASS |
| Открыто | Выключен | «Войти снова», без объявления «Сессия завершена». | PASS |
| Открыто | Включён | «Войти снова», без объявления «Сессия завершена». | PASS |

Во всех четырёх валидных комбинациях BFF вернул `401`, защищённое содержимое исчезло, диалог остался на карточке. Зарегистрирован один DOM `focusin` на кнопке «Войти снова». Системный Enter после речи запустил штатный вход с `returnUrl=/app/positions/btc`. Один диагностический прогон с потерей фокуса исключён и повторён.

В закрытом сценарии NVDA произносил «Войти снова, кнопка», затем «кнопка, Войти снова». Точный источник второго произнесения не установлен. В открытом сценарии Chrome оставил тот же узел диалога с обновлённым заголовком и перевёл фокус на новую кнопку. Speech Viewer зафиксировал только «Войти снова, кнопка».

**Результат речи принят владельцем с двумя указанными ограничениями.** Полного `PASS` матрицы NVDA нет. [Amendment v1.1](https://github.com/vbondarev/intelligence.trade.system/issues/230#issuecomment-7106128763)

Контрольный `session-timing.spec.ts` со штатным сроком сессии прошёл в Chromium **4/4**. Windows WebKit [#226](https://github.com/vbondarev/intelligence.trade.system/issues/226), приёмка G‑08 и условия релиза сохраняются.
